# Иконки

`app.svg` — иконка приложения, `tray-*.svg` — состояния в трее. `.ico` собраны
из SVG и содержат 16/20/24/32 (трей) и 16…256 (приложение): Windows выбирает
размер сам в зависимости от DPI, и если нужного нет — масштабирует ближайший
с заметными артефактами.

Пересобрать после правки SVG:

    make icons

## Почему знак именно такой

Пик асимметричный, с провалом ниже базовой линии. Симметричный треугольник
мозг читает как гору или букву «Λ»; узнаваемым ударом пульса его делает именно
провал. Проверено отрисовкой в 16px — на этом размере живёт большая часть
иконок в трее.

Состояние «пауза» отличается **формой** (ровная линия), а не только цветом.
Цветом одним пользоваться нельзя: часть людей его не различает, а Windows в
некоторых режимах рисует иконки трея приглушённо.

Плитка под знаком нужна, чтобы иконка одинаково читалась на светлой и тёмной
панели задач — у прозрачного знака контраст зависит от темы пользователя.
